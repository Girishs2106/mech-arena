How to Put MechPrep Arena Online for Free in 3 Minutes

OPTION 1 · BEST FOR NODE + GEMINI AI

Deploy Free on Render.com

  1. Create a free GitHub account and push the extracted mechprep folder to a new GitHub repository (we included render.yaml ready to go).
  2. Sign in to Render.com (Free Tier) and click New + → Web Service.
  3. Select your GitHub repository. Render automatically detects npm start (`node server.js`).
  4. In Render's Environment Variables, optionally add GEMINI_API_KEY (free from Google AI Studio) so server-side AI tutoring and PDF generation work for all users.
  5. Click Create Web Service — your site goes live at https://your-site.onrender.com with free HTTPS!
OPTION 2 · INSTANT STATIC HOSTING

Deploy Free on Vercel or Netlify

  1. Because our upgraded PDF → QP & Guide engine runs client-side with PDF.js and built-in local heuristics, the entire site works even without a backend server!
  2. Go to Vercel.com (or Netlify Drop) and import your project folder (vercel.json is already pre-configured).
  3. Your site deploys globally in 20 seconds on a free .vercel.app domain.
  4. Once live, sign up at Google AdSense, paste your Publisher ID in the Revenue Configuration panel above, and place your downloaded ads.txt in the public/ folder.
